# CareFlow OPD — Hospital Outpatient Booking System

## About the Project

CareFlow OPD is a web-based Hospital Outpatient Department (OPD) Booking System developed to improve the appointment booking process for patients and hospital staff. The system allows patients to find suitable doctors, check doctor availability, book appointments, receive token numbers, and view their upcoming queue numbers. It also helps hospital administrators manage doctor information, schedules, appointments, and patient queues more efficiently. The main purpose of this project is to reduce the difficulties patients face when finding doctors and checking their availability, while making the outpatient booking process more convenient and organized.

## Project Objectives

The main objectives of CareFlow OPD are to simplify the outpatient appointment booking process, help patients find doctors according to their medical needs, and provide clear information about doctors and their available schedules. The system also aims to generate token numbers for appointments and allow patients to check their upcoming queue numbers. In addition, it helps administrators manage appointment schedules, monitor queue progress, and organize patient appointments.

## System Features

### Patient Interface

The patient interface allows users to register, log in, and manage their personal information. Patients can view doctor details, medical specializations, and available appointment schedules before selecting a suitable doctor, date, and time. After successfully booking an appointment, the system provides a token number that patients can use to identify their appointment in the queue. Patients can also view their upcoming queue numbers, check appointment statuses, cancel or reschedule eligible appointments, and reschedule completed appointments for medical follow-up when necessary.

### Admin Interface

The admin interface allows administrators to manage user accounts, add or update doctor information, remove doctors, and manage doctor schedules. Administrators can manage patient appointments and token queues through a combined Appointment section. They can also call the next waiting patient, update appointment statuses, and monitor the progress of patient appointments.

### Appointment and Token Management

The system uses five statuses to represent appointment and token progress: Waiting, Called, In Operation, Completed, and Cancelled. These statuses help patients and administrators understand the current state of each appointment and support the organization of the outpatient queue.

## Technologies Used

The CareFlow OPD prototype is developed using HTML5 to create the website structure, CSS3 to design the layout and visual appearance, and JavaScript to implement interactive features. GitHub is used for source code management and team collaboration, while GitHub Pages can be used to publish the frontend prototype online.

## How to Run the Prototype

To run the prototype locally, download or clone the project repository and open the folder containing the prototype files. Ensure that `index.html`, `styles.css`, and `script.js` are kept together in the same folder. Open `index.html` in a web browser to explore the patient and admin interfaces and test the available prototype interactions.

## Project Scope and Limitations

This project focuses on designing and demonstrating the user interface and interactive workflows of a Hospital Outpatient Department Booking System for academic coursework. The current version is a frontend prototype and is not connected to a live backend server or database. Therefore, features requiring persistent data storage, real authentication, or live queue synchronization may require additional development.

## Future Improvements

Future development may include backend and database integration, secure user authentication, real-time queue updates, automated notifications, and improved appointment management. These improvements could help transform the prototype into a more complete hospital outpatient booking solution.
